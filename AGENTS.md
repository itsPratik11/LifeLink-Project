## Project Summary
This project is a high-fidelity clone of the Life Link Blood Donor App landing page, now featuring a fully functional User Dashboard and a modern, high-energy Hero section. It features a professional design with bold red accents, clear calls to action, and unique features like real-time blood donation tracking ("Blood Journey") and a comprehensive donor dashboard.

## Tech Stack
- Framework: Next.js (App Router)
- Language: TypeScript
- Styling: Tailwind CSS
- Icons: Lucide React
- Animation: Framer Motion
- Components: Custom React components and shadcn/ui components

## Architecture
- `src/app/`: Contains the main page, layout, and dashboard routes.
- `src/app/dashboard/`: Contains the User Dashboard implementation with its own layout and sidebar.
- `src/components/sections/`: Modularized sections of the landing page for better maintainability.
- `src/components/ui/`: Reusable UI components including the Sidebar, Cards, and Buttons.
- `src/app/globals.css`: Contains the theme variables and base styles derived from the Life Link branding.

## User Preferences
- Follows a modern, youth-focused, high-energy design aesthetic.
- Favors bold typography and interactive CSS/Framer Motion animations.

## Project Guidelines
- Maintain high accessibility while pushing for distinctive, "non-AI slop" aesthetics.
- Use the provided theme variables for consistency but don't shy away from bold accents.
- Keep the dashboard interface clean and actionable with clear icons and descriptions.
- Ensure all tracking features have smooth, high-quality animations.

## Common Patterns
- Modular component-based architecture for landing page sections.
- Responsive design using Tailwind CSS utility classes.
- Sidebar-based navigation for administrative or user dashboard areas.
- Framer Motion for entrance and state-based animations.
- Alternating "Zig-Zag" row layouts for storytelling and information hierarchy.
- Use of high-quality Unsplash photography with rounded corners and gradient glows.
